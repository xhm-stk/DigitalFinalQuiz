Digital Logic & System Design - Ultimate Master Guide (Full Text + Mini Graphics)

1. คณิตศาสตร์ลอจิก & ระบบเลขฐาน (Number Systems)

ทฤษฎีสัญญาณเบื้องต้น:
- Analog Signal: สัญญาณต่อเนื่อง (Continuous Signal) มีขนาดไม่คงที่ สัญญาณรบกวน (Noise) แทรกแซงได้ง่าย
- Digital Signal: สัญญาณไม่ต่อเนื่อง (Discrete Signal) มี 2 สถานะคือ 0 (Low) และ 1 (High) ทนทานต่อ Noise

1.1 การแปลงฐาน (Radix Conversion) แบบละเอียด:

แปลง ฐาน 10 เป็น ฐาน 2 (จำนวนเต็ม): ใช้วิธีหารสั้นด้วย 2

ตัวอย่าง: $25_{10} \rightarrow X_2$

25 / 2 = 12 เศษ 1 (LSB)
12 / 2 = 6 เศษ 0
6 / 2 = 3 เศษ 0
3 / 2 = 1 เศษ 1
1 / 2 = 0 เศษ 1 (MSB)
→ นำเศษมาเรียงจากล่างขึ้นบน: 110012

แปลง ฐาน 10 เป็น ฐาน 2 (ทศนิยม): ใช้วิธีคูณด้วย 2

ตัวอย่าง: $0.625_{10} \rightarrow X_2$

0.625 × 2 = 1.250 (บิตแรกสุด หน้าจุด)
0.250 × 2 = 0.500
0.500 × 2 = 1.000 (จบเมื่อหลังจุดเป็น 0)
→ นำเลขหน้าจุดมาเรียงจากบนลงล่าง: 0.1012

1.2 ระบบเลขมีเครื่องหมาย (Signed Numbers):

  • Sign Magnitude: บิตซ้ายสุด (MSB) คือเครื่องหมาย 0=บวก, 1=ลบ (ข้อเสีย: มีค่า 0 สองค่าคือ 0000=+0 และ 1000=-0)
  • 1's Complement: กลับบิต 0↔1 ทุกตำแหน่ง
  • 2's Complement: ทำ 1's Comp แล้วบวก 1 ที่ LSB (ระบบที่ CPU ทั่วโลกใช้)
การลบเลขด้วย 2's Complement:
แทนที่จะสร้างวงจรลบ (Subtractor) คอมพิวเตอร์จะใช้วงจรบวก (Adder) โดยใช้หลักการ A - B = A + (-B)
ตัวอย่าง: 7 - 5 (ในระบบ 4 บิต)
1. A = 7 = 0111
2. B = 5 = 0101 → แปลงเป็น 2's Comp จะได้ 1010 + 1 = 1011 (-5)
3. นำมาบวกกัน: 0111 + 1011 = 10010
4. ตัดตัวทด (Carry) บิตที่ 5 ทิ้ง → ผลลัพธ์ 0010 = 2 (ถูกต้อง!)

1.3 มาตรฐาน IEEE 754 (ทศนิยม 32 บิต):

โครงสร้าง: [1-bit Sign] | [8-bit Exponent (Bias 127)] | [23-bit Fraction (Mantissa)]
สูตร: Value = (-1)S × 1.F × 2E-127
ตัวอย่างแปลง 9.75 เป็น IEEE 754:
1. แปลงเป็นฐาน 2: $9 = 1001_2$, $0.75 = 0.11_2$ → รวม $1001.11_2$
2. เลื่อนจุด (Normalize): $1.00111_2 \times 2^3$
3. S (Sign) = 0 (เพราะเป็นค่าบวก)
4. E (Exponent) = $3 + 127 = 130_{10} = 10000010_2$
5. F (Fraction) = เอาเฉพาะหลังจุด = 00111 (เติม 0 ให้ครบ 23 บิต)
ผลลัพธ์: 0 10000010 00111000000000000000000

2. รหัสไบนารี่ & การแก้ไขข้อผิดพลาด (Binary Codes)

การจัดกลุ่มรหัส:
- Weighted Code: รหัสถ่วงน้ำหนัก แต่ละบิตมีค่าประจำหลัก (เช่น BCD 8421)
- Unweighted Code: รหัสไม่ถ่วงน้ำหนัก นำมาคำนวณทางคณิตศาสตร์ไม่ได้ (เช่น Excess-3, Gray Code)

2.1 BCD (Binary Coded Decimal 8421):

ใช้ 4 บิตแทนเลขฐานสิบ 1 หลัก (0-9) โดยรหัส 1010 (A) ถึง 1111 (F) ถือเป็นสภาวะที่ไม่ใช้งาน (Don't Care)

กฎเหล็กการบวก BCD:
เนื่องจาก BCD นับแค่ 0-9 ถ้าผลบวก 4 บิตใดๆ เกิน 9 (1001) หรือมีตัวทด (Carry) ล้นออกไปหลักถัดไป ต้องบวกปรับแก้ด้วย 0110 (เลข 6) เสมอ
ตัวอย่าง: 8 + 5 = 13
1000 (8) + 0101 (5) = 1101 (13) ซึ่งเกิน 9!
บวกปรับแก้: 1101 + 0110 = 1 0011 → แยกเป็น 0001 0011 = 13 ในรหัส BCD

2.2 รหัสอื่นๆ:

  • Excess-3: รหัสเพิ่ม 3 นำ BCD มาบวก 0011 มีคุณสมบัติ Self-complementing
  • ASCII Code: มาตรฐานตัวอักษร 7 บิต (A=41H/65, a=61H/97, 0=30H/48, Space=20H)
  • Gray Code: รหัสป้องกันความผิดพลาด ข้อมูลที่อยู่ติดกันจะเปลี่ยนค่าแค่ 1 บิตเสมอ (ลด Glitch ในเซนเซอร์หมุน/Encoder)

2.3 Error Detection & Correction (ตรวจสอบและแก้ไขข้อมูล):

  • Parity Bit: เช็คได้แค่ว่าผิดหรือไม่ แต่แก้ไม่ได้ (Even Parity = บิต 1 รวมเป็นเลขคู่, Odd Parity = บิต 1 รวมเป็นเลขคี่)
  • Hamming Code: ตรวจจับและ แก้ไขได้ 1 บิต (Single Error Correction)
วิธีสร้างรหัส Hamming Code (7,4): ข้อมูล 4 บิต (D), แทรก Parity 3 บิต (P)
โครงสร้าง: P1 P2 D3 P4 D5 D6 D7 (แทรก P ที่ตำแหน่ง $2^n$)
สมมติส่งข้อมูล D = 1011 (เรียงลงตำแหน่ง D3=1, D5=0, D6=1, D7=1)
การหาค่า P (สมมติใช้ Even Parity - XOR กันต้องได้ 0):
- P1 เช็คตำแหน่ง 1,3,5,7 → $P_1 \oplus 1 \oplus 0 \oplus 1 = 0 \rightarrow P_1 = 0$
- P2 เช็คตำแหน่ง 2,3,6,7 → $P_2 \oplus 1 \oplus 1 \oplus 1 = 0 \rightarrow P_2 = 1$
- P4 เช็คตำแหน่ง 4,5,6,7 → $P_4 \oplus 0 \oplus 1 \oplus 1 = 0 \rightarrow P_4 = 0$
รหัสที่ส่งออกไปคือ: 0 1 1 0 0 1 1
*หากฝั่งรับคำนวณ Parity ใหม่แล้วผิด สมมติ P1 และ P4 ผิด แสดงว่าบิตที่ 1+4 = 5 ผิด ให้กลับบิตที่ 5 ก็จะแก้ไขข้อมูลได้ทันที!

3. ลอจิกเกต & พีชคณิตบูลลีน (Mini-Gates)

AND: Y = A · B
(อนุกรม) ออก 1 เมื่อ In=1 ทุกตัว
OR: Y = A + B
(ขนาน) ออก 1 เมื่อมี In=1 แม้แต่ตัวเดียว
NOT: Y = A' หรือ A
Inverter ส่วนกลับ 0 เป็น 1
NAND: Y = A · B
*Universal Gate (สร้างเกตอื่นได้หมด)
NOR: Y = A + B
*Universal Gate (สร้างเกตอื่นได้หมด)
XOR: Y = A ⊕ B = AB+AB
ออก 1 เมื่อ In ต่างกัน (Odd Parity)
XNOR: Y = A ⊙ B = AB+AB
ออก 1 เมื่อ In เหมือนกัน (Even Parity)

ทฤษฎีพีชคณิตบูลลีนที่ควรจำ:

A + 0 = A
A + 1 = 1
A · 0 = 0
A · 1 = A
A + A = A
A · A = A
A + A = 1
A · A = 0
A + AB = A (ดึงตัวร่วม)
A + AB = A+B
De Morgan's Theorem (ทฤษฎีเดอมอร์แกน):
สูตรจำ: "หั่นบาร์ยาว เปลี่ยนเครื่องหมาย (+ เป็น · / · เป็น +)"
A + B = A · B (NOR เปลี่ยนรูปเป็น Bubble-AND ได้)
A · B = A + B (NAND เปลี่ยนรูปเป็น Bubble-OR ได้)

4. สวิตชิ่งฟังก์ชัน & K-Map (Minimization)

ฟังก์ชันมาตรฐาน (Standard Forms):

  • SOP (Sum of Product / Minterm): Y = Σm
    ดูจากบรรทัดที่ Y=1 (ตัวแปรปกติ=1, บาร์=0) เช่น ABC
  • POS (Product of Sum / Maxterm): Y = ΠM
    ดูจากบรรทัดที่ Y=0 (ตัวแปรปกติ=0, บาร์=1) เช่น (A+B+C)

Karnaugh Map (K-Map): เครื่องมือลดรูปสมการด้วยกราฟิก

AB \ CD00011110
00m0m1m3m2
01m4m5m7m6
11m12m13m15m14
10m8m9m11m10

กฎการวง K-Map:

  1. การเรียงช่องต้องเป็นแบบ Gray Code (เปลี่ยนทีละ 1 บิต: 00, 01, 11, 10) เพื่อให้ช่องที่ติดกันในตารางมีตัวแปรต่างกันแค่ตัวเดียว
  2. ต้องวงให้ครอบคลุมเลข 1 ให้หมด โดยขนาดวงต้องเป็น 2n (1, 2, 4, 8, 16 ช่อง)
  3. วงยิ่งใหญ่ สมการที่ได้จะยิ่งสั้น (ตัวแปรที่ค่าเปลี่ยน 0↔1 ในวงนั้นจะถูกตัดทิ้ง)
    *จากรูปด้านบน วง 4 ช่องสีส้ม ตัวแปร A(0) และ D(1) คงที่, B และ C เปลี่ยนค่า → ได้คำตอบ Y = AD
  4. สามารถวงพับขอบ (Wrap-around) ซ้าย-ขวา หรือ บน-ล่าง ทะลุกันได้
  5. Don't Care (X): ให้มองเป็น 1 หากนำมารวมแล้วทำให้วงใหญ่ขึ้น ถ้านอกวงให้มองเป็น 0 ไม่ต้องไปสนใจ
คำศัพท์สำคัญใน K-Map:
- Implicant: กลุ่มย่อยของ 1 ใดๆ ในตาราง
- Prime Implicant (PI): วงขนาดใหญ่ที่สุดที่เป็นไปได้
- Essential PI (EPI): วง PI ที่มีเลข 1 อย่างน้อยตัวหนึ่งซึ่ง ไม่ถูกวงอื่นทับ (สมการคำตอบสุดท้ายบังคับต้องมีวงนี้)

5. วงจรคอมบิเนชั่น (Combinational Circuits)

คุณสมบัติหลัก: เอาต์พุตขึ้นอยู่กับอินพุต ในวินาทีนั้นเท่านั้น (No Memory / No Feedback)

5.1 วงจรบวกเลข (Adders):

TypeInputsOutputsEquations
Half AdderA, BSum, CoutS=A⊕B, Cout=A·B
Full AdderA, B, CinSum, CoutS=A⊕B⊕Cin, Cout=AB+Cin(A⊕B)

*หมายเหตุ: โครงสร้างวงจร Full Adder สร้างจากการใช้ 2 Half Adder ประกอบร่วมกับ 1 OR Gate

5.2 วงจรจัดการเส้นทางข้อมูล (Data Routing):

  • Encoder (เข้ารหัส): เปลี่ยนการกดปุ่มให้เป็นเลขฐานสอง (เช่น $2^n$ In → $n$ Out)
    *Priority Encoder: หากกดปุ่มหลายอันพร้อมกัน จะให้สิทธิ์บิตที่มีค่าสูงสุดก่อน
  • Decoder (ถอดรหัส): เปลี่ยนฐานสองเป็นสายเลือกอุปกรณ์ ($n$ In → $2^n$ Out) นิยมใช้เปิด Chip Select (CS)
  • Multiplexer (MUX): ตัวเลือกข้อมูล ($2^n$ In → $1$ Out) มี Selector เป็นตัวสับสวิตช์ว่าจะให้ Input ไหนผ่านไปออกที่ Output
    สมการ 2-to-1 MUX: Y = S·I0 + S·I1
  • De-Multiplexer (De-MUX): ตัวกระจายข้อมูล ($1$ In → $2^n$ Out)

5.3 7-Segment & Multiplexing:

  • Common Cathode (ขาลบร่วม): หลอดติดเมื่อจ่ายลอจิก 1 (High)
  • Common Anode (ขาบวกร่วม): หลอดติดเมื่อจ่ายลอจิก 0 (Low)
  • การสแกน (Multiplexing): กรณีมี 7-segment หลายหลัก (เช่น 4 หลัก) การต่อแบบธรรมดาจะเปลืองพอร์ต MCU มาก จึงใช้เทคนิค Share Bus โดยนำขา a-g ของทุกตัวมาต่อถึงกันทั้งหมด แล้วใช้วงจรสวิตช์ (Transistor) คอยเปิด/ปิดขา Common ทีละหลักสลับกันด้วยความเร็วสูง (>60Hz) ทำให้ตาคนมองเห็นว่าหลอดไฟติดพร้อมกันทุกหลัก เป็นการประหยัดพอร์ตและฮาร์ดแวร์อย่างมหาศาล

6. วงจรซีเควนเชียล & สัญญาณเวลา (Sequential)

หัวใจสำคัญ: Output ในปัจจุบัน ขึ้นอยู่กับ Input ปัจจุบัน และ สภาวะที่ผ่านมา (มี Memory ป้อนกลับ/Feedback)

6.1 ประเภทของวงจร Sequential:

1. Synchronous (มี Clock กลางควบคุม):
อุปกรณ์ทุกตัวรับสัญญาณนาฬิกา (Clock) ลูกเดียวกัน เปลี่ยนสภาวะพร้อมกันหมด ขจัดปัญหาความหน่วงสะสม (เสถียรและเร็วที่สุด)

2. Asynchronous (ไม่มี Clock หรือต่อทอดกัน):
เปลี่ยนสภาวะตามยถากรรม หรือรับ Clock ส่งต่อกันไปเรื่อยๆ (Ripple) ทำให้เกิด Propagation Delay สะสม แบ่งเป็น:
  • Fundamental Mode: เปลี่ยนสถานะเมื่อ Input เปลี่ยนแปลง โดยมีข้อแม้ว่า Input ต้องไม่เปลี่ยนพร้อมกันหลายตัว และต้องรอให้วงจรนิ่ง (Stable) ก่อนเปลี่ยน Input ครั้งต่อไป
  • Pulse Mode: คล้าย Fundamental แต่อินพุตมาในรูปของ Pulse สั้นๆ

6.2 เครื่องจักรสถานะจำกัด (FSM - Finite State Machine):

  • Mealy Machine: Output เกิดจาก State ปัจจุบัน + Input ปัจจุบัน (ถ้า Input เปลี่ยนกะทันหัน Output ก็เปลี่ยนทันที อาจเกิด Glitch ได้ง่าย)
  • Moore Machine: Output เกิดจาก State ปัจจุบันเท่านั้น (วงจรเสถียรกว่า เปลี่ยนแปลงตามจังหวะ Clock เท่านั้น)

6.3 การวิเคราะห์ Timing (Timing Diagram Analysis):

  • Setup Time ($t_{su}$): เวลาต่ำสุดที่ข้อมูล (Data) ต้อง มารอก่อน ขอบสัญญาณนาฬิกา และต้องนิ่งห้ามแกว่ง
  • Hold Time ($t_h$): เวลาต่ำสุดที่ข้อมูลต้อง ค้างสถานะเอาไว้ หลังจากขอบสัญญาณนาฬิกาผ่านไปแล้ว
  • Propagation Delay ($t_{pd}$): เวลาความหน่วงที่วงจรต้องใช้ในการประมวลผลภายใน (จาก Input วิ่งไปถึง Output)
  • *หากละเมิดกฎ $t_{su}$ หรือ $t_h$ ฟลิปฟลอปจะเข้าสู่สภาวะ Metastability (เอ๋อ ไม่รู้จะออก 0 หรือ 1)

7. ฟลิปฟลอป & แลตช์ (Latches & Flip-Flops)

ความแตกต่างที่สำคัญ:
- Latch: อุปกรณ์แบบ Level-triggered (ไวต่อระดับไฟ) ทะลุผ่านทันทีที่ไฟเป็น 1
- Flip-Flop: อุปกรณ์แบบ Edge-triggered (ไวต่อขอบสัญญาณ) เปลี่ยนค่าเฉพาะจังหวะขอบขาขึ้น (↑) หรือขาลง (↓) เท่านั้น

*หมายเหตุ: โครงสร้างพื้นฐานของ SR Latch แบบไขว้สร้างจาก 2 NOR Gate (ห้ามป้อน S=1, R=1 จะทำให้ Q และ Q' = 0 ซึ่งผิดกฎ Invalid State)

7.1 สมการลักษณะ (Characteristic Equations):

  • SR FF: Qnext = S + RQ (สภาวะ S=R=1 ถือเป็น Invalid State ห้ามใช้)
  • D FF (Data): Qnext = D (หน่วงเวลาข้อมูล 1 คล็อก)
  • JK FF: Qnext = JQ + KQ (แก้ปัญหา SR โดยเมื่อ J=K=1 สถานะจะ Toggle (สลับค่า))
  • T FF (Toggle): Qnext = T ⊕ Q (สร้างจากการช็อตขา J และ K เข้าด้วยกัน)
การแก้ปัญหา Race Around ใน JK Flip-Flop:
หากป้อน J=K=1 ในฟลิปฟลอปที่ไม่มีระบบกันขอบสัญญาณ เมื่อ Clock กว้างกว่าเวลาหน่วงของเกต สถานะจะสลับ 0-1-0-1 รัวๆ จนคุมไม่ได้
วิธีแก้: ออกแบบเป็น Master-Slave JK (ใช้ฟลิปฟลอป 2 ตัวต่ออนุกรมกัน) Master รับข้อมูลตอนขาขึ้น(↑) และบังคับให้ Slave ปล่อยข้อมูลตอนขาลง(↓) เท่านั้น ข้อมูลจึงเปลี่ยนแค่ 1 ครั้งต่อ 1 รอบ Clock

7.2 พอร์ตบังคับแบบอะซิงโครนัส (Asynchronous Clear/Preset):

ขา PR (Preset) และ CLR (Clear) มักจะเป็น Active Low มีอำนาจสูงสุดในวงจร สามารถบังคับให้ Q เป็น 1 หรือ 0 ได้ทันทีโดย ไม่ต้องรอจังหวะ Clock (นิยมใช้รีเซ็ตตอนเปิดระบบ)

8. วงจรเลื่อนข้อมูล (Shift Registers)

นำ D Flip-flop มาต่ออนุกรมกัน ทำหน้าที่เป็นหน่วยความจำเก็บชั่วคราวและเคลื่อนย้ายข้อมูล

ประเภทหลัก 4 ชนิด:

  • SISO (Serial In - Serial Out): อนุกรมเข้า อนุกรมออก (ใช้หน่วงเวลา Delay 1 บิต/Clock)
  • SIPO (Serial In - Parallel Out): อนุกรมเข้า ขนานออก (แปลงสัญญาณสายเดี่ยวแตกออกหลายเส้น เช่น จอ LCD)
  • PISO (Parallel In - Serial Out): ขนานเข้า อนุกรมออก (โหลดข้อมูลขนานยิงส่งสายสัญญาณเส้นเดียว)
  • PIPO (Parallel In - Parallel Out): ขนานเข้า ขนานออก (รวดเร็วที่สุด ใช้เป็น Buffer เก็บข้อมูลในหน่วยประมวลผล)
การประยุกต์วงจรเลื่อนเป็นวงจรนับ (Shift Counters):
1. Ring Counter (แบบวงแหวน): โยงเอาต์พุต Q ตัวสุดท้าย กลับไปเข้า D ตัวแรกสุด (Mod-N)
สภาวะ (4-bit): 1000 → 0100 → 0010 → 0001 → (วนกลับ)

2. Johnson / Twisted-Ring Counter: โยงเอาต์พุต Q (แบบตรงข้าม) ตัวสุดท้าย กลับไปเข้า D ตัวแรกสุด (Mod-2N คุ้มค่ากว่า Ring Counter)
สภาวะ (3-bit): 000 → 100 → 110 → 111 → 011 → 001 → 000

9. วงจรนับ (Counter Circuits & Design)

9.1 วงจรนับแบบอซิงโครนัส (Asynchronous / Ripple Counter):

  • สัญญาณ Clock ป้อนเข้าแค่ FF ตัวแรก (LSB) เท่านั้น
  • ตัวถัดไปรับสัญญาณ Clock มาจากเอาต์พุตของตัวก่อนหน้า ทำให้เกิด **Propagation Delay สะสม** (ทำงานช้าและมีข้อจำกัดด้านความถี่)
  • นับขึ้น (UP): ใช้ FF ขอบลง(↓) โยงเอาต์พุต Q ไปเป็น CLK ตัวถัดไป
  • นับลง (DOWN): ใช้ FF ขอบลง(↓) โยงเอาต์พุต Q ไปเป็น CLK ตัวถัดไป
  • การตัด Mod-N: หากต้องการนับ Mod-10 (0 ถึง 9) เมื่อถึงสภาวะที่ 10 (1010) ให้ดึงสาย Q3 และ Q1 ไปเข้า NAND Gate แล้วป้อนกลับไปล้างค่าที่ขา CLR ของทุกตัว (เกิด Glitch ได้ง่าย)

9.2 ขั้นตอนการออกแบบ Synchronous Counter (ป้อน CLK ทุกตัว):

โจทย์: ออกแบบวงจรนับขึ้น 0 → 1 → 2 → 3 → 0 (ใช้ JK Flip-flop)
Step 1: กำหนดตัวแปร (2 บิต แทน 0-3 ได้) ใช้ FF 2 ตัว คือ A และ B
Step 2: สร้าง State Table + Excitation Table

11. โค้ด Verilog HDL เบื้องต้น (Hardware Description)

Verilog HDL: ภาษาที่ใช้บรรยายโครงสร้างของฮาร์ดแวร์ระดับเกต หรือระดับพฤติกรรม เพื่อนำไปโปรแกรมลงบนชิป FPGA

11.1 การออกแบบ Combinational - วงจร Full Adder:

module Full_Adder( input A, B, Cin, output Sum, Cout ); // การเขียนแบบ Dataflow (Continuous Assignment) ใช้ assign สำหรับวงจร Combinational assign Sum = A ^ B ^ Cin; assign Cout = (A & B) | (Cin & (A ^ B)); endmodule

11.2 การออกแบบ Sequential - D Flip-Flop (Edge-Triggered):

module D_FF( input clk, reset, D, output reg Q // ต้องประกาศ output เป็น reg เมื่อใช้งานภายใน always block ); // always block จะถูกกระตุ้นเมื่อเกิดขอบขาขึ้นของ clk หรือขอบขาขึ้นของ reset always @(posedge clk or posedge reset) begin if (reset) Q <= 1'b0; // Asynchronous Reset (มีอำนาจล้างค่าทันทีไม่ต้องรอคล็อก) else Q <= D; // เลื่อนค่า D ไปไว้ใน Q แบบ Non-blocking Assignment (<=) ซึ่งบังคับใช้กับวงจร Sequential end endmodule

11.3 การออกแบบวงจรนับ - 4-bit Up Counter:

module Up_Counter( input clk, reset, output reg [3:0] count // ประกาศเป็นอาเรย์ขนาด 4 บิต (บิต 3 ถึง บิต 0) ); always @(posedge clk or posedge reset) begin if (reset) count <= 4'b0000; // เคลียร์ค่าเริ่มต้นกลับเป็น 0 else count <= count + 1; // สั่งนับขึ้นทีละ 1 ทุกๆ ครั้งที่มี Clock เข้ามา end endmodule
